- HTML5 semántico

## Interacciones en JavaScript

- Texto que se escribe solo en la presentación
- Aparición de secciones al hacer scroll
- Menú fijo que marca la sección activa
- Botón de volver arriba
- Formulario con contador de caracteres y validación
- Respeta la preferencia de reducir movimiento del dispositivo

## Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Smith-dev546/mi-portafolio.git
   ```
2. Abre `index.html` en el navegador. No necesita instalación.

## Cómo publicarlo

1. Sube el proyecto a GitHub.
2. Importa el repositorio en [Netlify](https://www.netlify.com/) o [Vercel](https://vercel.com/).
3. No requiere comando de build. La carpeta de publicación es la raíz del proyecto.

## Cómo personalizarlo

- **Proyectos:** edita la lista `project-list` en `index.html`.
- **Colores:** cambia las variables al inicio de `styles.css` (`:root`).
- **Frases de la presentación:** modifica el arreglo `frases` en `script.js`.
- **Correo de contacto:** cámbialo en `index.html` y en `script.js`.
